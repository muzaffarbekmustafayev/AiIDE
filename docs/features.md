# Features Breakdown

## 1. File Explorer & Editor
- **Tree View:** Displays a hierarchical view of the workspace.
- **Operations:** Create, delete, rename, and drag-and-drop (move) files and folders.
- **Editor Features:** 
  - Open multiple file tabs.
  - Support for various file formats (JS, PY, MD, JSON, TXT).
  - Real-time saving and manual editing.

## 2. Integrated Terminal
- **Real Shells:** Spawns actual shells based on OS availability (PowerShell on Windows, Bash/Zsh on Linux/Mac).
- **Multiple Tabs:** Supports opening and managing multiple terminal instances concurrently.
- **Real-time Execution:** Direct interaction with the underlying OS through the IDE.

## 3. Version Control (Git)
- **Change Detection:** Automatically detects modified files in the workspace.
- **1-Click Commit:** Provides a quick "Commit Changes" UI button to instantly stage and commit current work.

## 4. Theming & Settings
- **Theme Selector:** A dropdown with 10+ editor/UI themes (e.g., VS Dark, Light, Dracula, Monokai, GitHub Dark, etc.).
- **Configurations:** General user preferences for font size, tab width, etc.

## 5. Mobile Connectivity & Remote Sessions
- Support for connecting to the IDE session remotely using a mobile phone.
- Secure connection through QR code scanning or entering an 8-digit randomly generated connection code.

## 6. AI Extensions
- Plug-in support for adding custom AI models (e.g., via OpenRouter API key) to spawn Agentic or Chat windows inside the IDE.
